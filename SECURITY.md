# Security

Xrotel Agents is a configuration and instruction package for use with OpenAI Codex.

Xrotel does not require users to provide OpenAI account credentials, API keys or ChatGPT authentication information to Xrotel.

Xrotel does not operate an intermediary proxy between the user and OpenAI and does not intentionally intercept Codex network traffic.

## Reporting a security concern

If you discover a security issue relating specifically to Xrotel Agents, please avoid publishing sensitive exploitation details in a public issue until the matter has been reviewed.

Security reports should contain:

* the affected Xrotel version;
* the affected file or component;
* reproduction information;
* the potential impact; and
* any suggested remediation if known.

Do not include passwords, API keys, access tokens or other credentials in reports.

## Scope

Problems caused by OpenAI Codex itself, operating systems, third-party models or unrelated software should be reported to the appropriate vendor.

Xrotel is an independent third-party project and is not affiliated with, sponsored by or endorsed by OpenAI.
